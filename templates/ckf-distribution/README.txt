Cyber Knights: Flashpoint 한국어 패치

설치
1. 게임과 Steam을 종료합니다. 설치 중 다시 실행하지 않습니다.
2. CyberKnights.exe가 있는 게임 폴더에 ZIP을 풉니다.
   구조: 게임폴더\cyberknights-ko\install.cmd
3. install.cmd를 실행합니다. 표시된 상위 게임 폴더가 맞으면 y를 입력합니다.
4. 게임 언어 메뉴에서 한국어를 선택합니다. 중국어 간체 슬롯을 사용합니다.

Python이나 별도 프로그램 설치, 인터넷 연결, 관리자 권한을 자동 요구하지 않습니다.
Windows PowerShell 5.1과 .NET Framework를 사용합니다. 보안 정책이나 백신이 차단하면
해당 오류를 확인하세요. 설치기는 시스템 실행 정책을 변경하거나 우회하지 않습니다.
게임은 로컬 NTFS 드라이브에 있어야 합니다. 네트워크 공유·WSL UNC 경로는 지원하지 않습니다.

검사와 제거
verify.cmd: manifest에 기록된 설치 파일 4개(v1) 또는 6개(v2)의 해시를 검사합니다. 게임 파일을 변경하지 않습니다.
uninstall.cmd: 설치 전 원래 파일로 복구합니다. 백업은 삭제하지 않습니다.
백업: 게임폴더\.cyberknights-ko-backup\패치버전
패치 폴더를 지우기 전에 uninstall.cmd를 실행하세요. 백업 폴더는 별도로 보존하세요.
패치 폴더를 이미 삭제/손상시켰다면 동일 버전 ZIP을 다시 풀고 uninstall.cmd를 실행하세요.
실패/중단 후에는 같은 버전 install.cmd를 다시 실행하거나 uninstall.cmd로 복구하세요.
원본 또는 이 패치와 다른 파일이 발견되면 중단합니다. 동시 변경을 교체 직후 발견하면
CONFLICT 상태로 중단하고 교체 직전 파일을 displaced-*.bin에 보존합니다.
이 경우 자동 재설치/복구하지 말고 백업 전체를 보존한 채 복구 지원을 요청하세요.
새 패치 버전으로 바꾸기 전에는 기존 패키지의 uninstall.cmd로 이전 패치를 제거하세요.
특히 v1에서 v2로 바꿀 때는 기존 v1 ZIP의 uninstall.cmd로 제거하고 원본 파일 복구를
확인한 뒤 새 v2 ZIP을 푸세요. 새 ZIP을 먼저 같은 cyberknights-ko 폴더에 덮어 풀면
기존 제거 도구를 잃습니다. v2 제거 뒤에도 원본 확인 후 v1을 다시 설치할 수 있습니다.
Steam 업데이트 후에는 이 버전의 패치를 강제로 적용하지 마세요.

범위와 제한
manifest.json에 image_status가 있으면 부분 이미지 포함 패치입니다.
README 첫 부분의 반영/미반영/보류 수와 게임 미확인 범위를 확인하세요. 영문 이미지 문구가 남아 있습니다.
이미지 포함 v2는 Steam build 25594089 또는 25697586의 고정 파일·guard 조합만 지원합니다.
다른 v2 build나 서로 다른 build의 이미지 파일 조합은 거부합니다. 지원 Steam 빌드와 패치 차수는 manifest.json에 기록돼 있습니다.
게임 폴더 이름 자체는 자유지만 cyberknights-ko는 실행 파일과 같은 폴더 바로 아래여야 합니다.
원본 빌드 파일의 SHA-256으로 호환성을 판정합니다. 다른 모드와 동시 적용은 지원하지 않습니다.
심볼릭 링크/junction/hardlink가 있는 경로는 지원하지 않습니다.
4개 또는 6개 파일 교체 전체가 하나의 원자적 작업은 아닙니다. 검증된 전체 백업을 먼저 만들고,
중단 시 해시를 확인한 뒤 복구합니다. 설치 중 게임/Steam/다른 설치기를 실행하지 마세요.
외부 프로그램의 동시 실행·쓰기까지 완전히 차단하는 설치기는 아닙니다.
저장 데이터, 계정/인증 파일, Steam Cloud 설정은 변경하지 않습니다.
이미 중국어로 생성된 저장 인물명은 자동 변환되지 않습니다. 새 이름은 한국어로 생성됩니다.
장소/시간 자막 3종과 v2의 튜토리얼·메뉴 이미지는 공용 자산이므로 다른 언어를 골라도 한국어로 표시됩니다.
최소 인게임 확인을 거쳤지만 모든 대사·분기·이미지 문구를 검증한 패치는 아닙니다.

배포 내용
이 ZIP은 COPY/ADD 차분, 설치/복구 코드, 설명과 폰트 라이선스만 포함합니다.
원본 게임 전체 파일, 실행 파일, 저장 파일, 인증 파일은 포함하지 않습니다.
한국어 폰트: Noto Sans CJK KR Regular (SIL OFL 1.1, FONT-LICENSE.txt 참조).
Steam 빌드별 첫 배포: cyberknights-ko-빌드.zip
동일 빌드 업데이트: cyberknights-ko-빌드-rc1.zip, -rc2.zip 등.

다운로드 신뢰
이 패키지는 실행 코드를 포함합니다. 신뢰하는 배포처에서만 받으세요.
실행 전에 PowerShell의 Get-FileHash 'ZIP파일명' -Algorithm SHA256 결과를
배포자가 ZIP 밖에 게시한 SHA-256과 비교하세요. ZIP 내부 해시만으로 배포자를 인증하지 않습니다.
